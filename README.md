# Histoire, analyse et applications des principaux frameworks de programmation quantique

Ce projet vise à dresser un état de l'art historique, technique et applicatif des différents frameworks de programmation quantique actuels. 

Commencez par le document IQ01_FrameworksQuantiques.pdf 

Ce dernier vous redirigera vers les documents additionnels lorsque nécessaire. 

### Documents additionnels 

Programmation-Quantique.ipynb : Explication des concepts fondamentaux de la programmation quantique

Grover.ipynb : Exlication complète de l'algorithme de Grover

TSP.ipynb : Code d'implémentation en informatique classique et quantique d'une instance du TSP (traveling salemsan problem)

basic_travaling_salesman.py : Implémentation naïve en informatique classique du traveling salesman problem
